# THE WORLD — Friday 20 November 2026

Entry for the make.fun bounty [news-image-20261120](https://make.fun/bounty/news-image-20261120): sum up 20 November's world news in one image.

A classic broadsheet front page, "THE WORLD", dated Friday 20 November 2026. Four lead stories in two columns — Cyclone Akvan's landfall in Odisha, the first three-way Trump–Xi–Putin summit closing in Shenzhen, the World Court's ruling that Myanmar committed genocide against the Rohingya, and US intelligence that Iran still holds at least 2,500 missiles — plus an IN BRIEF strip along the bottom with five more stories of the day. Black ink on aged newsprint, with a thin red rule under the masthead.

`main.ts` (Node 22, standard library only) copies `entry.png` to the output directory; run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
